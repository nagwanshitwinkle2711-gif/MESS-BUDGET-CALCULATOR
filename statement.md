# Mess Budget Calculator – Project Statement

## 1. Project Title

**Mess Budget Calculator**

---

## 2. Problem Statement

Students living in hostels or using mess facilities often have a fixed monthly budget for food and other mess-related expenses. It can become difficult to keep track of individual expenses and know how much money has been spent or how much budget is remaining.

The **Mess Budget Calculator** is a simple Python-based application that helps students set their monthly mess budget, record their expenses, view recorded expenses, and generate a budget report.

The project provides a simple menu-based interface so that users can manage their mess budget without needing complex calculations.

---

## 3. Project Scope

The project focuses on basic monthly mess budget and expense management.

The application allows the user to:

* Set a monthly mess budget.
* View the current monthly budget.
* Add individual expenses.
* View all recorded expenses.
* Delete an expense when required.
* Calculate total expenses.
* Calculate the average expense per recorded expense.
